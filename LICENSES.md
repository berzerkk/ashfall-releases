### Armes jouables Quaternius intégrées dans weapon_skins.json

Les 3 armes FantasyProps déjà présentes dans `assets/quat/props/` sont maintenant référencées comme skins d'armes
dans `data/weapon_skins.json` (section `kind` et `base`). Elles remplacent les modèles Hunyuan correspondants.

| Fichier GLB | kind (défaut) | base (spécifique) | Textures |
|---|---|---|---|
| `Sword_Bronze.glb` | `sword` | `Épée Rouillée` | 256×256 JPEG85, CC0 |
| `Axe_Bronze.glb` | `axe` | `Hachette` | 256×256 JPEG85, CC0 |
| `Shield_Wooden.glb` | `shield` | `Écu de Bois` | 512×512 JPEG85, CC0 |

**Note technique** : Auto-normalisation via `weapon_visual._normalize_xform` (grand axe → +Y os, tête = bout le plus
large, échelle réelle par kind). Les JPEG85 dégradent légèrement les normales mais restent acceptables en vue
isométrique. Ne pas réoptimiser sans inspecter les textures résultantes. Si `flip: true` ou `rot_fix` nécessaire,
ajouter dans weapon_skins.json après test visuel `tests/weapon_grip_check.tscn`.
