# Ashfall

Hack & slash fantasy.

## Installer
1. Télécharger **Ashfall.exe** dans la dernière [release](https://github.com/berzerkk/ashfall-releases/releases/latest).
2. Le lancer. C'est tout : le jeu se met à jour tout seul au démarrage quand une nouvelle version est publiée.

Les sauvegardes sont dans `%APPDATA%\Godot\app_userdata\Ashfall` et ne sont jamais touchées par les mises à jour.
